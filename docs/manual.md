# Hardware Manual {#manual}

## Innova PIO36 Reference Manual

The complete hardware reference manual for the Innova PIO36 board is available here:

**[Download PIO36 Manual (PDF)](MAN-000139920_R2.pdf)**

### Manual Contents

The manual includes detailed information on:

- **Hardware specifications** - Pin layouts, electrical characteristics, dimensions
- **Modbus register map** - Complete list of holding and input registers
- **PWM output configuration** - Duty cycle control, frequency settings
- **Analog input specifications** - Voltage ranges, resolution, scaling
- **Network configuration** - IP settings, Modbus TCP protocol details
- **Installation and wiring** - Connection diagrams and safety guidelines

### Quick Reference

For quick reference without opening the full manual:

- **PWM Outputs**: 36 channels, 0-100% duty cycle, registers 1-36
- **Analog Inputs**: 8 channels, 0-10V range, registers 37-44
- **Network**: Modbus TCP, default port 502
- **Default IP**: 192.168.52.209
